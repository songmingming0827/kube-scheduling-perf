# Agent Scheduler 场景 3 Worker 4 七轮对照报告

日期：2026-09-01（Asia/Shanghai）

## 结论

在 Agent Scheduler Worker `4` 下，`masterperf1` 相对 `master` 的裁剪后平均吞吐从 `762.772 pods/s` 提升到 `936.232 pods/s`，提升 `22.74%`。P50、P90、P99 平均调度延迟分别降低 `50.75%`、`58.03%`、`58.67%`。Binding window 平均值从 `13.1102 s` 缩短到 `10.6820 s`，减少 `2.4282 s`、降低 `18.52%`，对应完成速度为 `1.2273×`。

裁剪规则严格以吞吐量为准：每个镜像各删除吞吐最高和最低的对应整轮，再对剩余 5 轮的 P50、P90、P99 和吞吐量求算术平均；没有独立裁剪延迟指标。
